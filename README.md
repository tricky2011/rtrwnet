# RTRWNet

Aplikasi billing dan operasional ISP/RTRWNet berbasis CodeIgniter 3, dengan pengelolaan pelanggan, multi-router, keuangan, work order, helpdesk, dan ONT.

Mulai dari [dokumentasi lengkap billing dan operasional](docs/13_DOKUMENTASI_LENGKAP_BILLING_RTRWNET.md), baseline source 22 Oktober 2026.

- [Spesifikasi teknis dan data](docs/14_SPESIFIKASI_TEKNIS_DAN_DATA.md)
- [Operasional, deployment, dan pengujian](docs/15_OPERASIONAL_DEPLOYMENT_DAN_PENGUJIAN.md)
- [Referensi endpoint dan source](docs/16_REFERENSI_ENDPOINT_DAN_SOURCE.md)
- [Indeks seluruh dokumentasi](docs/README.md)

Dokumentasi membedakan fitur yang ditemukan di source, konfigurasi yang diperlukan, dan batas yang belum diverifikasi di runtime. Kredensial, data pelanggan, dan dump produksi tidak disertakan.
